# Drive Artifact Deployer

Public documentation and privacy policy for **Drive Artifact Deployer**, a personal automation tool for synchronizing built novel EPUB artifacts from GitHub Actions to personal Google Drive storage.

## Published Pages

- **Homepage:** https://kamahir0.github.io/drive-artifact-deployer/
- **Privacy Policy:** https://kamahir0.github.io/drive-artifact-deployer/privacy.html

## Scope & Disclosures

- **OAuth Scope:** `https://www.googleapis.com/auth/drive.file`
- **Application Type:** Personal development / CI sync utility
- **Compliance:** Adheres to Google API Services User Data Policy, including Limited Use requirements.

For questions or issues, please open an issue in this repository.

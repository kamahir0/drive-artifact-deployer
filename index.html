Drive Artifact Deployer

Personal Automation Tool / 個人用同期ツール

概要 (Overview)

Drive Artifact Deployer は、個人の小説執筆ワークフローにおいて、GitHub Actions の CI/CD パイプラインで生成された EPUB 電子書籍ファイルを開発者本人の Google Drive に自動同期・バックアップするための個人専用ツールです。

利用対象と目的 (Audience & Purpose)

  • 個人専用ツール： 本ツールは開発者個人の執筆ワークフロー専用に設計・運用されており、一般ユーザー向けの公開サービスではありません。
  • 外部ユーザー登録なし： 外部ユーザー向けのサインアップ、アカウント登録、ログイン機能、一般公開機能は一切提供していません。
  • 単一用途： GitHub Actions 上でビルド・検証された EPUB アーティファクトを、本人の Google Drive の指定フォルダに安全に転送・配備することのみを目的としています。

動作の仕組み (How it Works)

Git リポジトリへのプッシュやプルリクエスト作成時に GitHub Actions が起動し、小説原稿から EPUB ファイルを自動生成します。生成された EPUB は、OAuth 2.0 認証を介して Google Drive の所定フォルダ（Deployments/）へ同期されます。

本ツールがアクセスするのは、本ツール自身が Google Drive 上に作成したファイルおよびフォルダのみです（OAuth スコープ: https://www.googleapis.com/auth/drive.file）。ユーザーの他の個人ファイルへのアクセス権限は要求せず、一切アクセスしません。

セキュリティとプライバシー： 本ツールの詳細なデータ取り扱い基準、Google Drive 上でのファイル操作規程、および利用権限の取り消し方法については、プライバシーポリシーをご確認ください。

English Summary

Drive Artifact Deployer is a private, personal utility used solely by the developer to synchronize built EPUB novel artifacts from GitHub Actions CI workflows to their personal Google Drive storage.

  • Personal Use Only: This application is not a public SaaS or multi-user service. There is no user registration or external login.
  • Restricted Operation: The tool only manages files created by itself under the https://www.googleapis.com/auth/drive.file scope. It never touches or inspects any other personal files.
  • Privacy Policy: For detailed disclosures regarding data access, retention, and revocation, please visit the Privacy Policy page.

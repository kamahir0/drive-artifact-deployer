プライバシーポリシー (Privacy Policy)

アプリケーション名: Drive Artifact Deployer | 最終更新日: 2026年10月13日

1. 本方針について

「Drive Artifact Deployer」（以下「本アプリ」）は、個人の小説制作・執筆ワークフローにおいて、CI/CD（GitHub Actions）でビルドされた電子書籍（EPUB）成果物を開発者本人の Google Drive へ自動転送・配備するために作成された個人用ツールです。

本アプリは一般公開されているマルチユーザー向けサービスではなく、開発者本人（または明示的に許可されたテストアカウント）のみが使用します。本プライバシーポリシーでは、本アプリが利用する Google API、アクセス権限、データの取り扱い、およびセキュリティについて説明します。

2. 使用する OAuth スコープ

本アプリは、以下の Google API スコープのみを要求・使用します。

  • https://www.googleapis.com/auth/drive.file
    権限内容: 本アプリ自身が Google Drive 上に新規作成したファイル、または本アプリを使用して開いたファイル・フォルダの閲覧・作成・編集・削除に限定された権限（Non-sensitive スコープ）。

本アプリは Google Drive 全体へのアクセス権限（drive や drive.readonly 等）を要求しません。Google Drive 内にあるユーザーの他の既存ファイル（写真、ドキュメント、私的フォルダなど）を閲覧、検索、変更、削除することは技術的・権限的に不可能です。

3. Google Drive 上で行う具体的なファイル操作

本アプリの実装（同期スクリプト）は、本アプリが管理対象として明示的に作成したファイル・フォルダのみを対象として、以下の操作を行います。

  • フォルダおよびファイルの作成 (Create): Google Drive 上に配備用ルートフォルダ（Deployments）を作成し、その配下にリポジトリ別・Git ブランチ別のフォルダ階層を作成して、生成された EPUB ファイルをアップロードします。作成されたアイテムには本アプリ専用のメタデータ（appProperties）が付与されます。
  • ファイル内容およびメタデータの更新 (Update): Git コミットの更新に伴い、既存の EPUB ファイルの内容およびビルド識別子（Git コミットハッシュ等）を最新状態に上書き更新します。
  • ファイルの削除 (Delete): 以下の正当な同期理由に限定して、本アプリ自身が作成したファイル・フォルダを削除します。
    • Git リポジトリ側で原稿が削除されたことに伴い、対応する配備済み EPUB ファイルを削除する場合（同期の整合性維持）。
    • ファイルの削除によって空になった配備用サブフォルダをクリーンアップする場合。
    • プルリクエストのクローズやブランチの削除に伴い、該当ブランチの一時プレビュー用フォルダ全体を削除する場合（ストレージ整理）。

他ファイルへの非干渉: 本アプリが付与した特定の管理識別子（appProperties）を持たないファイルやフォルダは、一切検索・更新・削除の対象としません。

4. データの保存先および第三者提供の有無

  • データの保存先: アップロードされた EPUB ファイルは、ユーザー本人の Google Drive アカウント内のみに保存されます。また、一時的なビルドアーティファクトは本人の GitHub リポジトリの GitHub Actions ランナー上でのみ扱われます。
  • 第三者提供の有無: 本アプリは、いかなるユーザーデータ、ファイル内容、認証情報も外部のサーバー、第三者企業、または広告トラッカー等に送信・共有・開示・販売しません。本アプリにはアナリティクスやトラッキングコードも一切含まれていません。

5. 認証情報の管理とセキュリティ

  • トークン管理: OAuth 2.0 のクライアント ID、クライアントシークレット、およびリフレッシュトークンは、GitHub リポジトリの暗号化された秘密情報（GitHub Actions Secrets）および開発者のローカル作業端末内（Git 管理外の保護ファイル）にのみ保管されます。
  • ログ保護: CI/CD 実行ログ、プルリクエスト、コミットログ等に認証情報が出力されないよう、マスキングおよび適切な除外処理が行われています。
  • データ通信: Google API とのすべての通信は、HTTPS (TLS) による暗号化通信を用いて行われます。

6. アクセス権限の取り消し方法

ユーザーはいつでも本アプリに対する Google アカウントへのアクセス許可を取り消すことができます。

  1. Google アカウントの「サードパーティ製のアプリとサービス」設定 にアクセスします。
  2. 一覧から Drive Artifact Deployer を選択します。
  3. 「アクセス権を削除」または「接続を解除」をクリックします。

権限を取り消すと、本アプリからの Google Drive への新規アクセスおよび同期は直ちに停止されます。

Privacy Policy (English Version)

Application Name: Drive Artifact Deployer
Last Updated: October 13, 2026

1. Purpose & Scope

Drive Artifact Deployer is a private personal utility used solely by the developer to synchronize built EPUB book artifacts from GitHub Actions CI workflows to their personal Google Drive storage. This is not a multi-user or commercial public service.

2. Google API Scopes

This tool requests only one scope:

  • https://www.googleapis.com/auth/drive.file — Permits viewing, creating, updating, and deleting only the specific files and folders created or opened by this application. It cannot view, access, or modify any other files in your Google Drive.

3. File Operations Performed on Google Drive

  • Create: Generates a dedicated deployment folder hierarchy (Deployments/) and uploads novel EPUB artifacts with specific metadata (appProperties).
  • Update: Updates existing EPUB files and build SHA tags when changes are pushed to Git.
  • Delete: Only deletes application-created artifacts when a novel source is removed from the Git repository, cleans up empty subfolders, or removes temporary branch preview folders when a pull request or branch is closed. It never deletes or touches files created outside this app.

4. Data Storage & Third-Party Sharing

All synchronized files remain solely within the user's personal Google Drive account and ephemeral GitHub Actions runners. No personal data, novel content, or authentication tokens are ever shared, transmitted, or sold to third parties. There are no tracking scripts or external telemetry.

5. Security & Credential Handling

OAuth client secrets and refresh tokens are strictly stored in encrypted GitHub Actions Secrets and local git-ignored files. Credentials are never printed in CI logs or committed to version control.

6. Revoking Access

You can revoke access to this application at any time via Google Account Permissions by finding "Drive Artifact Deployer" and clicking "Remove Access".

7. Contact

For inquiries or issues regarding this application, please open an issue on the GitHub repository: https://github.com/kamahir0/drive-artifact-deployer/issues.

Google API Services User Data Policy Compliance:
Drive Artifact Deployer's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.
